# YouTube Thumbnail AI Classifier

A learning project for building a browser extension that displays an estimated
AI-generated likelihood score on YouTube thumbnails.

The current prototype adds a placeholder score badge to thumbnails, including
new thumbnails loaded while scrolling. It does not perform real AI
classification yet.

## Run in Brave

1. Open `brave://extensions`.
2. Enable **Developer mode**.
3. Select **Load unpacked**.
4. Choose the `extension` folder.
5. Open or refresh YouTube.

After changing the extension files, reload the extension and refresh YouTube.
